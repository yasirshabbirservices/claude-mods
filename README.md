# claude-mods

Claude Code mods by Yasir.

## token-weather

A band above the prompt showing how full the context window is: a weather word (Clear, Cloudy, Showers, Storm, Compact soon), percent used, tokens used / window, and a chart of the last 12 turns.

## Install

```bash
claude plugin marketplace add yasirshabbirservices/claude-mods
claude plugin install token-weather@yasir-mods --scope user
```
